💸 FinanceFlow

FinanceFlow is a personal Python project created to build a complete financial management system.

The main goal is to provide a simple, fast, and keyboard-focused way to manage personal finances directly through the terminal.

The project started as an automation tool for the "Minhas Finanças" desktop application, but its direction has evolved into building a standalone financial software with its own data storage and business logic.

Features
Add expenses from the terminal
List expenses
Update expenses
Delete expenses
Store financial data in JSON
Input validation

Keyboard-focused terminal experience

The project follows a keyboard-first approach, aiming to make financial management fast and practical without requiring the mouse for everyday operations.
